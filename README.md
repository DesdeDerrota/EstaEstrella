First off, what is a Starbie?
----------------------------------------

A Starbie is a little nickname used to describe the HackClub creation of the week, 
a tamagotchi like device capable of interacting with the user. It's named a Starbie 
for copyright reasons (takes some creative liberties from the device known as a 
Starboy, image below.

Why make a Starbie?
----------------------------------------

I made a Starbie as apart of a multiweek challenge for Hack Club, the Starbie being the beginner project for the week 1 of Half Life, 
the name of the challenge. While I do have experience with hardware to some degree, to be frank, I have a lot to learn, so I chose
Starbie as a means to improve my skills.

Challenges
----------------------------------------

Along this journey, I had numerous, numerous, problems, all of which stemmed from ineptness. To create my project, I had to learn,
or understand, how to utilize the tools of KiCAD. KiCAD, for those who don't understand, is a computer aided circuit modeling software
which allows one to create a circuit, on the PCB's we all know and love. PCB, also for those who don't understand, stands for Printed
Circuit Board (covering all the bases, I think that I would appreciate it if I was younger). Using the designs provided by the wonderous
SharKing Studios, who designed the Starbie, I had to essentially follow the order and structure of the board he made. Sounds easy, until
put in practice, and the smallest error is what sets you back for about and hour or so (I know, it happened more than I want to admit).

Personal Touches
----------------------------------------
- The board has been modified to be squared and rounded.
- The PCB has two, non function related slots which serve to fit the board into a custom case.
- The character in the PCB is custom, made from a previous project and imported into the bitmap format.
