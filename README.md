First off, what is a Starbie?
----------------------------------------

A Starbie is a little nickname used to describe the HackClub creation of the week, 
a tamagotchi like device capable of interacting with. It's named a Starbie for copyright
reasons (takes some creative liberties from the device known as a Starboy, image below.

Why make a Starbie?
----------------------------------------

I made a Starbie as apart of a multiweek challenge for Hack Club, the Starbie being the beginner project for the week 1 of Half Life, 
the name of the challenge. While I do have experience with hardware to some degree, to be frank, I have a lot to learn, so I chose
Starbie as a means to improve my skills.
